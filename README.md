# Skazka Runtime

**RU:** Публичные contracts для удалённой конфигурации и изменений, которые могут доставляться без нового APK.

**EN:** Public contracts for remote configuration and changes that can be delivered without a new APK.

## Что здесь будет / What belongs here

- Runtime Config schema;
- APP / CFG / REG / SRV / OPS version contracts;
- client-side validation;
- compatibility rules;
- signed metadata contracts;
- safe reference examples.

## Граница / Boundary

Production-конфигурация, signing keys, приватные endpoints и серверная публикация runtime-пакетов остаются закрытыми.

## Основной принцип / Main principle

Контракт публичный и проверяемый. Конкретное production-состояние — нет.
